# Galuh Esa Ibrahim - Portfolio

Personal portfolio website showcasing my projects, skills, and professional experience as a Full Stack Developer.

## Live

[galuh80.github.io](https://galuh80.github.io)

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Getting Started

```sh
# Clone the repository
git clone https://github.com/Galuh80/Galuh80.github.io.git

# Navigate to the project directory
cd Galuh80.github.io

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Build

```sh
npm run build
```
